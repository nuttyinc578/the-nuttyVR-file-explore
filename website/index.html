A FEW GOOD QUESTIONS

A little clarity.

Before you step inside.

Is this a VR app or a regular phone app?+

NuttyVR is an Android APK designed for a floating, resizable window inside a headset. The interface uses large controls and the headset’s system pointer, controller, or hand input. This version is a 2D panel in VR, with device testing still needed across supported headsets.

Can I install and launch APK files?+

Yes. Tap a standalone .apk file in NuttyVR, choose Install APK, allow installation if prompted, and confirm Android’s installer. Then choose Open app. APK bundles such as .apks and .xapk are not supported.

Can I extract ZIP, TAR and RAR files?+

Yes. Tap a .zip, .tar, .tar.gz, .tgz or single-volume .rar file and choose Extract. NuttyVR creates a new folder beside it, keeps existing files, and shows progress with a Cancel button. RAR4 and RAR5 are supported. Password protected archives, multipart RAR and archive links are not supported.

What can NuttyVR access?+

You choose. Grant shared-storage access or use Android’s folder picker for a specific folder. USB storage can appear if the headset exposes it. Android’s restrictions on private app folders, including Android/data and Android/obb, still apply.

Do I need an account or an internet connection?+

No. Download the APK here, then use the app offline. NuttyVR has no account requirement, ads, or network permission. The website uses GitHub to provide downloads and release information.

What does “nightly” mean?+

A nightly is a development build that can change as the project grows. This download is the latest published nightly. Check the release notes for its source and build details, and use disposable files when trying new file operations.
